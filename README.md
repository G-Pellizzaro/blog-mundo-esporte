# Mundo Esporte — Blog sobre Esporte

Trabalho da disciplina de CSW (Construção de Software / Desenvolvimento Web).

Blog temático sobre **Esporte**, desenvolvido em HTML5 e CSS3.

## Estrutura do site

- `index.html` — Home (resumo do blog + conteúdos de destaque com imagens que são links)
- `futebol.html` — Editoria Futebol
- `basquete.html` — Editoria Basquete
- `volei.html` — Editoria Vôlei
- `contatos.html` — Página de Contatos (com formulário)
- `css/estilo.css` — Folha de estilos
- `img/` — Imagens dos destaques

Cada página utiliza as estruturas básicas de HTML: `head`, `body`, `header`,
`main` e `footer`, além do elemento `<nav>` com os 5 itens de navegação
mantidos em todas as páginas.
